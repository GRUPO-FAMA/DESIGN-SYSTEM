Numbered section header ("01 · Qué es el Openday · 3 horas") on a top hairline; picks Syne only for titles of ≤4 words without FAMA.

```jsx
<SectionHead num="02" title="Método FAMA" label="Tres fases"/>   // → Space Grotesk (contains FAMA)
<SectionHead num="03" title="Testimonios" label="Alumnos"/>       // → Syne
```
Use `syneAllowed(text)` anywhere else you need the same decision.
